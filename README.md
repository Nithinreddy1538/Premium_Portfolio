# 📖 About

This is my personal developer portfolio built using **React.js**, showcasing my skills, projects, technologies, and professional journey as a Full Stack Developer.

The portfolio features modern UI/UX principles, smooth animations, glassmorphism, interactive effects, responsive layouts, and premium design to create an engaging experience for visitors.

It highlights my technical expertise, academic projects, certifications, and contact information in a clean and professional manner.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Nithinreddy1538/Portfolio.git
```

Move into project

```bash
cd Portfolio
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Open

```
http://localhost:5173
```

---

# 🌐 Deployment

Build project

```bash
npm run build
```

Preview build

```bash
npm run preview
```

Deploy using

- Vercel
- Netlify
- GitHub Pages
